## 与提案仍有差异的细节

| 项目 | 当前实现 | 剩余工作 |
| --- | --- | --- |
| 单资源预览循环 | 支持一次预览、停止、复位，以及待机清单连续试用 | 尚无独立的单资源预览循环开关 |
| 保存反馈 | 复用设置页固定页脚、“有未保存的修改”和“设置已保存”；退出有保存／放弃选择 | 尚未显示修改数量和“已应用到某角色：平时播放 N 个动作”的具体摘要 |
| 来源说明 | 有效规则统一派生，界面显示“来自模型默认／你设置的” | 尚未完整细分“模型声明／名称自动匹配／手动配置”三类来源 |
| 区域重叠反馈 | 具有显式顺序、优先级调整和编辑／试用模式，运行时按规则命中 | 尚无独立的“此处将触发……”命中反馈展示 |
| 伴学表情恢复 | 支持定时恢复；资源详情可设定时或再次触发关闭，运行时伴学统一使用定时策略 | 尚无单独的“事件结束后恢复”策略选择器 |
| 大量资源的目录 | 使用受限高度滚动目录，当前样例为 10 项 | 尚未进行超大目录基准测试或启用虚拟列表 |

这些项目应作为后续补齐项，不能用“主流程完成”替代。配置导入／导出、批量改名、多表情组合及独立资源导入则仍属于提案明确延后的范围。

旧 `Live2DCapabilitySummary.tsx` 本次按“保留所有工作区文件”的要求入库并标记弃用，未被当前页面导入，不恢复旧入口；后续可单独清理。早期 [优化记录](live2d-optimization.md) 按历史资料保留，当前使用说明以 [Live2D 文档](live2d.md) 为准。
