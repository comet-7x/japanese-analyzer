# 句子翻译

本地或模型解析成功后，在句子解析页自动翻译；未完成、失败或取消的解析不触发。
默认来源是 MyMemory，已保存的手动来源选择会保留。可在译文下拉菜单或
「设置 → 翻译服务」选择默认翻译服务，或在主界面切换「当前模型 / 翻译服务」。原文会发送给所选翻译服务；
本地分词本身不需要上传原文。

## 可选邮箱与额度

MyMemory 不要求为 `de` 联系邮箱参数注册账号，也不需要邮箱密码或 OAuth。
未填写时匿名调用；填写后直接携带该邮箱。官方公开额度为匿名 5,000 字符/天，
提供有效联系邮箱后 50,000 字符/天；实际可用额度由服务方判定。
这不是账号额度绑定，不保证每个邮箱都是独立额度池，也不承诺
「先匿名 5,000，再额外使用 50,000」；应用不会切换身份或循环重试来绕过限制。
服务端转发默认使用部署的网络出口，不伪造用户 IP。多人使用同一服务器时，
匿名额度可能共享出口，不能承诺每位用户都获得独立匿名额度。

如果部署的可信反向代理会覆盖某个请求头、写入一个真实终端用户 IP，可设置
`MYMEMORY_CLIENT_IP_HEADER` 为该头名称（例如代理覆盖的 `X-Real-IP`）。
应用仅在显式配置且该头为单个有效 IPv4/IPv6 时，将其作为官方 `ip` 参数传递。
代理必须移除客户端伪造值；未经配置时忽略所有转发头和正文中的 IP。

邮箱格式错误时在保存前提示。上游拒绝邮箱时提示检查地址，不引导注册；
额度耗尽、超时及网络失败保留解析结果。用户可以稍后手动重试或选择当前模型，
不会自动降级为收费的模型翻译。

## 缓存与请求合并

- 只把成功的 MyMemory 原文、目标界面语言和译文持久化到当前浏览器。
  最多 100 条、约 1 MiB 内容预算，每条保留 30 天；邮箱、模型密钥和模型润色结果
  不写入翻译缓存。浏览器存储不可用时仍可在当前页面使用内存缓存。
- 相同原文、目标语言直接复用成功缓存，切换邮箱也不重复消耗额度。
  「重新翻译」跳过成功缓存；失败、空译文、被取消请求及额度告警不缓存。
- 同一页面中相同原文、目标语言和联系邮箱的并发请求共用一次网络请求；
  各视图可以独立取消，所有订阅者都离开后才取消上游。
  不同浏览器或标签页的进行中请求不合并。
- 「设置 → 翻译服务 → 清除翻译缓存」立即删除缓存，保留已显示的译文。
  清除之前开始的请求完成后也不会重新写回被清除的缓存。
