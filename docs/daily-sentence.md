# 今日一句

采用“静态句包随应用发布，后台检查更新，用户点击即时换句”。首页立即显示当天最后选句；没有选句时，从已缓存候选或内置句库选择。网络请求只更新候选池，不修改当前显示内容。桌面版使用随应用启动的 Next.js API，不依赖账号或公共网站部署。

## 即时选句

标题旁的「换一句」保留固定水平间距，标题保留箭头动画。每次点击同步选择一个新句子，只使用假名完整且具有当前语言译文的候选，不完整的资料仅留在后台，没有合格候选时立即使用本地句库。断网时也可使用之前缓存的完整候选。点击不会等待网络、不显示网络等待状态、不触发模型调用。

正式展示的例句必须满足：分词可精确还原原文，每个含汉字的词都有有效假名，当前界面语言有非空译文。应用只消费预设句包，不请求或解析 Tatoeba 实时接口。恢复当天选句、切换语言和手动换句都检查此标准；旧缓存中缺注音或当前语言译文的句子会替换为完整例句。

同一事件内的重复点击合并；不同次点击各选一句。后台请求进行中、失败或超时时按钮仍可使用。新候选只供下一次选句使用，后台完成不会再次切换当前句子。

## 候选池与持久化

`japaneseAnalyzer:dailyPool:v1` 保存当前选句、最多 500 条候选、近期记录以及各语言的同步时间和失败退避时间。候选在加入时洗牌，消费后移除；按原文和来源 ID 排除最近 30 天内最多 200 条已选记录，并排除当前原文。本地选句也记入原文去重历史。

静态句包的未使用候选可持续离线使用；旧版实时接口候选最多保留 7 天。日期沿用日本时间，当天最后选句会在重启或刷新后保留。日本零点、窗口恢复焦点和可见性变化时检查日期。旧版 `japaneseAnalyzer:dailySentence:v2` 的近期记录自动迁入新池，当前句子仅在注音及当前语言译文完整时恢复，后续以新池为准，避免恢复旧的在线缓存。页面启动等待已保存的界面语言恢复完成后再选句，防止默认语言误替换其他语言的当天选句。

存储损坏时安全回退；写入失败时仍在内存中保留候选、已消费记录和当前选句，语言切换不会恢复旧句。无法写入本机存储时，退出页面后的持久化无法保证。

内置 60 条项目编写的例句，每条包含分词、读音及简体中文、繁体中文、英语、韩语译文。本地索引和剩余顺序保存在 `japaneseAnalyzer:dailyDeck:v1`，使用 Fisher–Yates 洗牌，一轮内不重复，轮次交界不立即重复。

## 后台同步与退避

页面启动、恢复联网、窗口聚焦或用户消费候选后检查补充条件。单个组件同一时间只有一个后台请求，点击换句不会取消或重建正在进行的补充请求。

当前语言的完整候选数不超过 3 条时，距上次成功同步至少 15 分钟可补充；候选充足时，24 小时后检查更新。失败后依次等待 15 分钟、30 分钟、1 小时，最长 6 小时再尝试。等待时间持久化，刷新页面、快速点击或反复触发联网事件都不会绕过退避。离线时暂停联网，恢复后仍遵守退避。

后台请求使用 `/api/daily-sentence?locale=...&refresh=1`。接口立即返回当前已验证的整包，不再直连 Tatoeba 随机接口，也不会因上游超时返回 503。候选池按界面语言筛选完整例句，不把其他语言译文冒充当前语言。浏览器为本地 API 保留 10 秒的开发编译余量，选句不等待这段请求。

可选服务器环境变量 `DAILY_SENTENCE_PACK_URL` 指向自己托管的同格式 JSON 文件。留空时只使用打包句库，无需部署在线服务。配置后，服务端最多每天后台检查一次，使用 ETag/304；下载上限 1 MB、5 秒超时，仅允许经现有地址校验的 HTTPS URL，不跟随重定向、不附带模型密钥或用户原文。错误、校验失败和版本回退都保留当前句包并退避重试，API 响应不等待更新。无需账号。

句包格式为 schema 3，要求完整注音及简中、繁中、英语、韩语四种译文。每个发布日期是不可变版本，同格式的更新包必须使用更新的日期，并携带正确的内容 SHA-256。旧 schema 1/2 缓存升级到四语 schema 3 时优先升级格式，保留已消费历史；若当前原句仍在句包中，原地补齐其注音和译文，不切换原句。普通同日包不会反复补入，旧格式也不能覆盖四语包。摘要用于检测损坏，可信来源依赖管理员配置的 HTTPS 地址，不提供数字签名认证。运行中的服务保留最后验证成功的包；浏览器持久保存已安装版本和未消费候选。

跨日、语言切换和组件卸载会取消旧后台请求；即使旧请求稍后返回，也不能写入新池或改变显示。

## 静态句包、来源与许可

原有 60 条四语言注音例句与新增 92 条句对均提供完整假名和四种译文。简体中文、繁体中文、英语、韩语界面使用完全相同的 152 条原句，首装即可离线使用；切换语言只切换译文，不改变当前完整例句。新包位于 `app/data/daily-sentences.json`；浏览器只读取已标注数据，不加载分词引擎或调用模型。构建及后台下载校验会拒绝缺少任何一种语言译文的发布包。

注音在构建阶段由锁定版本的 Kuromoji 0.1.2 / IPADIC 离线生成，复用项目的分词适配层，并对两处已发现的语境多音字添加限定原句的修正。不把本地词典注音标成 Tatoeba 提供的原始读音，也不声称通用词典能够保证所有语境读音正确；未能补齐或对齐读音的句子会使构建失败，不进入发布包。原文与来源实际提供的英语译文保持不变。

新增的简中、繁中和韩语译文由项目基于日文原句补充，保存在 `scripts/daily-sentence/translations.tsv`（列为日文来源 ID、简中、繁中、韩语）。全部作为预设译文展示，不在卡片中额外显示补充译文标签。补充译文使用 CC BY 2.0 FR，数据中的 `provider: project` 仅用于记录来源，不伪造 Tatoeba 译文 ID 或作者。这些预设译文不是 Tatoeba 原生译文或独立人工审校保证。使用时不联网翻译，不消耗用户的模型额度。

数据来自 [ManyThings 的 Tatoeba 日英导出](https://www.manythings.org/anki/)。该导出采用已识别的日语母语贡献者句子和维护者检查过的英语句子。项目选取日常短句，保留原文、译文及各自的 Tatoeba ID、作者和许可；这不代表 JLPT 分级或独立人工校对保证。原句与显示的英语译文分别提供来源页及许可链接。

许可为 CC BY 2.0 FR；归属说明见 `LICENSES/daily-sentences.md`，许可副本见 `LICENSES/CC-BY-2.0-FR.html`。原有 60 条项目编写的例句与第三方语料分开保存。语料不包含音频。

## 可复现生成与发布

`scripts/daily-sentence/source.lock.json` 固定原始 ZIP 地址、SHA-256、获取日期、92 条选中句对的 ID/原始行指纹，以及项目补充译文快照的 SHA-256。句包版本由发布日期和内容摘要组成。`approved.tsv` 与 `translations.tsv` 保存原始行及补充译文，确保上游 ZIP 将来更新后仍可离线复现。生成时拒绝未知格式、重复或多余的译文 ID、缺失译文、变更过的选中句、缺少的 ID 或快照校验失败。

```bash
# 日常检查：无需联网，开发启动和生产构建也会执行
npm run daily:check
# 默认按已保存的选中原始行重建，无需联网
npm run daily:build
# 已下载 ZIP：按固定选择重建，结果应与提交文件完全一致
npm run daily:build -- --archive /path/to/jpn-eng.zip
# 维护者或 CI：获取固定上游，再校验和重建
npm run daily:build -- --download
```

更新语料需要先检查原始变更，更新锁文件和选句指纹，再重建并审阅句包。不会把随机抓取结果自动发布为学习材料。`.github/workflows/daily-sentences.yml` 为相关 PR 和手动运行提供离线来源重建校验；手动运行可另外核查当前上游 ZIP（上游已更新时会要求审阅并更新锁文件），不自动推送或发布。提供在线更新时，将验证后的 JSON 原样上传到自己的 HTTPS 对象存储或 CDN，再设置环境变量；当前代码不创建或假定已有公共托管服务。
