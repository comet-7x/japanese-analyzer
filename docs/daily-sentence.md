# 今日一句

采用随应用发布的静态句库，所有选句直接在浏览器本地完成。已删除每日一句 API、后台联网取句、远程句包更新、定时同步、重试及网络超时逻辑。网页和桌面版均无需句源服务、账号或模型 Key。

## 即时选句

标题旁的「换一句」保留固定水平间距，标题保留箭头动画。每次点击同步选择一个新句子。同一事件内的重复点击合并；不同次点击各选一句。点击无需网络、不触发模型调用；点击原句或标题时才交给现有解析功能。

正式展示的例句必须满足：分词可精确还原原文，每个含汉字的词都有有效假名，当前界面语言有非空译文。恢复当天选句、切换语言和手动换句都检查此标准。页面启动等待已保存的界面语言恢复完成后再选句，防止默认语言替换其他语言的当天选句。

## 候选池与持久化

`japaneseAnalyzer:dailyPool:v1` 保存当前选句、内置句包版本、未使用候选及近期记录。候选加入时使用 Fisher–Yates 洗牌，消费后移除；按原文和来源 ID 排除最近 30 天内最多 200 条已选记录，并排除当前原文。本地选句也记入原文去重历史。日期沿用日本时间，当天最后选句会在刷新或重启后保留。日本零点、窗口恢复焦点和可见性变化时检查日期，恢复联网不触发请求或切换句子。

未使用的内置候选可持续离线使用。另有 60 条四语例句保存在 `DAILY_SENTENCES` 中，其洗牌顺序使用 `japaneseAnalyzer:dailyDeck:v1` 保存，一轮内不重复，轮次交界不立即重复。

旧版 `japaneseAnalyzer:dailySentence:v2` 的近期记录自动迁入新池。安装应用内置句包时，匹配原句会原地补齐其注音和译文；旧版远程句包及不在内置句库内的选句被替换。应用升级后以内置句包为准，相同版本不会重新填入已消费的候选。

存储损坏时安全回退；写入失败时仍在内存中保留候选、已消费记录和当前选句，语言切换不会恢复旧句。无法写入本机存储时，退出页面后的持久化无法保证。

## 句库更新

句包格式为 schema 3，要求完整注音及简中、繁中、英语、韩语四种译文，版本由发布日期及内容 SHA-256 组成。维护者修改并校验内置数据后，随应用新版本发布；运行时不下载更新。构建检查内容摘要、来源指纹及四语完整性。

## 静态句包、来源与许可

原有 60 条四语言注音例句与新增 92 条句对均提供完整假名和四种译文。简体中文、繁体中文、英语、韩语界面使用完全相同的 152 条原句，首装即可离线使用；切换语言只切换译文，不改变当前完整例句。新包位于 `app/data/daily-sentences.json`；浏览器只读取已标注数据，不加载分词引擎或调用模型。构建校验会拒绝缺少任何一种语言译文的发布包。

注音在构建阶段由锁定版本的 Kuromoji 0.1.2 / IPADIC 离线生成，复用项目的分词适配层，并对两处已发现的语境多音字添加限定原句的修正。不把本地词典注音标成 Tatoeba 提供的原始读音，也不声称通用词典能够保证所有语境读音正确；未能补齐或对齐读音的句子会使构建失败，不进入发布包。原文与来源实际提供的英语译文保持不变。

新增的简中、繁中和韩语译文由项目基于日文原句补充，保存在 `scripts/daily-sentence/translations.tsv`（列为日文来源 ID、简中、繁中、韩语）。全部作为预设译文展示，不在卡片中额外显示补充译文标签。补充译文使用 CC BY 2.0 FR，数据中的 `provider: project` 仅用于记录来源，不伪造 Tatoeba 译文 ID 或作者。这些预设译文不是 Tatoeba 原生译文或独立人工审校保证。使用时不联网翻译，不消耗用户的模型额度。

数据来自 [ManyThings 的 Tatoeba 日英导出](https://www.manythings.org/anki/)。该导出采用已识别的日语母语贡献者句子和维护者检查过的英语句子。项目选取日常短句，在句包元数据和许可文件中保留原文、译文及各自的 Tatoeba ID、作者和许可；这不代表 JLPT 分级或独立人工校对保证。首页卡片只展示预设原句、假名和译文，不显示来源与许可链接。

许可为 CC BY 2.0 FR；归属说明见 `LICENSES/daily-sentences.md`，许可副本见 `LICENSES/CC-BY-2.0-FR.html`。原有 60 条项目编写的例句与第三方语料分开保存。语料不包含音频。

## 可复现生成与发布

`scripts/daily-sentence/source.lock.json` 固定原始 ZIP 地址、SHA-256、获取日期、92 条选中句对的 ID/原始行指纹，以及项目补充译文快照的 SHA-256。句包版本由发布日期和内容摘要组成。`approved.tsv` 与 `translations.tsv` 保存原始行及补充译文，确保上游 ZIP 将来更新后仍可离线复现。生成时拒绝未知格式、重复或多余的译文 ID、缺失译文、变更过的选中句、缺少的 ID 或快照校验失败。

```bash
# 日常检查：无需联网，开发启动和生产构建也会执行
npm run daily:check
# 默认按已保存的选中原始行重建，无需联网
npm run daily:build
# 已下载 ZIP：按固定选择重建，结果应与提交文件完全一致
npm run daily:build -- --archive /path/to/jpn-eng.zip
# 维护者或 CI：获取固定上游，再校验和重建
npm run daily:build -- --download
```

更新语料需要先检查原始变更，更新锁文件和选句指纹，再重建并审阅句包。不会把随机抓取结果自动发布为学习材料。`.github/workflows/daily-sentences.yml` 为相关 PR 和手动运行提供离线来源重建校验；手动运行可另外核查当前上游 ZIP（上游已更新时会要求审阅并更新锁文件），不自动推送或发布。验证后的句包随应用代码发布。
