# 虚拟角色服务

Live2D 是可关闭的客户端插件。启用后，桌面页面左侧显示透明角色舞台，并依据当前朗读音频驱动模型嘴部参数。角色由用户导入；项目不附带模型或 Cubism Core。

## 准备 Cubism Core

1. 阅读 [Live2D 官方 SDK 下载页](https://www.live2d.com/en/sdk/download/web/)上的软件许可协议，按协议取得 Cubism SDK for Web。
2. 将 SDK 中的 `live2dcubismcore.min.js` 放到 `public/live2d/core/live2dcubismcore.min.js`。插件只在启用并加载模型时按需读取 `/live2d/core/live2dcubismcore.min.js`。
3. 启动项目后打开「设置 → 虚拟角色服务」，导入模型 ZIP，选中角色并保存设置。

Core 文件已被 Git 忽略。它不在 npm 依赖中，也不会从第三方 CDN 自动下载。缺少该文件时，角色卡片会显示加载错误；项目其余功能仍可使用。桌面打包会复制 `public/`，因此维护者在构建发行包时也需单独准备 Core，并核对许可允许相应的打包与分发方式。[官方 SDK 手册](https://docs.live2d.com/en/cubism-sdk-manual/cubism-sdk-for-web/)说明 Core 受专有协议约束，未在 GitHub 发布。

## 导入与切换角色

在「设置 → 虚拟角色服务」选择 ZIP。ZIP 应包含 Cubism 3/4/5 的 `.model3.json`、该配置引用的 `.moc3`、纹理及其他资源，并保持原有相对目录。一个 ZIP 含多个模型时需选择主模型。当前不支持旧版 Cubism 2 `.model.json`、远程 URL 或内置预设。

导入在浏览器本地完成，ZIP 原文件保存在 IndexedDB，设置保存在 localStorage；模型文件不会因导入而上传到应用服务器。可在同一设置页切换或删除角色。ZIP 上限为 32 MiB，解压后总量上限为 128 MiB；单文件上限为 32 MiB，最多 256 个条目。导入失败时检查模型引用路径、文件大小和浏览器可用存储空间。

可用 SDK 自带的 `Samples/Resources/Hiyori` 做本地检查：把整个 `Hiyori` 文件夹压成 ZIP，确保包内路径仍是 `Hiyori/Hiyori.model3.json`。该样例在 Cubism SDK for Web 5-r.4 中通过了本项目的导入和浏览器渲染验证。样例模型仅用于本地检查；公开发布前须单独核对其免费素材许可与模型条款。

IndexedDB 按站点来源隔离。更换浏览器、域名、端口，或清除站点数据后，需要重新导入。桌面版通常复用本地端口以保留数据，端口重置也会形成新的存储来源。请自行保留原 ZIP 作为备份。

## 朗读联动

启用「口型跟随语音」后，插件对已有 TTS 音频计算短时音量曲线，以播放器的实际播放时间采样，暂停或结束时闭嘴。系统语音接口没有可解码的音频数据时，仅提供粗略的说话动画。模型的 `.model3.json` 如声明 `Groups → LipSync` 参数，插件使用该组；否则尝试 `ParamMouthOpenY`。没有对应参数的模型不会张嘴。调节「口型灵敏度」可适配不同模型与音频。此功能按音量控制开合，并不解算音素或日语元音口型。[Live2D 官方口型说明](https://docs.live2d.com/en/cubism-sdk-manual/lipsync/)给出了模型参数配置与音量驱动方式。

插件需要浏览器支持 WebGL、IndexedDB 和 Web Audio。启用并加载本地角色后，角色脚下显示紫色透明胶囊，替代右下角聊天入口；模型不可用、加载失败或停用插件时保留原聊天入口。角色区域可直接拖动，移动超过 5px 后开始拖拽；键盘聚焦角色后使用方向键移动，Shift 加大步长。桌面和手机各自保存位置。角色拖拽区域会拦截覆盖范围内的正文操作，区域以外仍可正常选词。

胶囊平时是细圆角线条，鼠标进入时展开「聊天｜阅读｜设置」SVG 菜单；触屏可点击展开，键盘聚焦也可展开。聊天时胶囊变成输入框，上方独立面板显示流式回复。输入区明确切换「当前句子」「自由聊天」，两种模式分别保留记录与草稿，每个已提交句子也有独立记录。句子模式显示原句摘要，只发送文本和当前句子上下文；自由聊天不附带页面原句，仅此模式允许图片附件。切换模式会中止原请求，迟到回复不能写入其他会话。普通聊天入口和胶囊共用这些会话。

自由聊天中，支持图片输入的 AI 模型可通过加号附加一张不超过 2 MiB 的 PNG/JPEG/WebP。图片以 `image_url` 消息部分直接发送给多模态模型，不先提取文字或生成描述。句子模式在界面和接口均禁止图片。文本模型不能发送图片；附件和含图历史在切换到文本模型后保留，需清空含图记录并移除附件，或切回支持图片的模型后才能继续发送。会话正文上限 9 MiB，前后端均做限制。

收起角色后仍可拖动短线移动胶囊，超过 5px 才认定拖拽，松开后保存位置。菜单在短线上方展开，短线保持可用；输入框和功能按钮不参与拖拽。键盘聚焦短线后可用方向键移动，Shift 加大步长。

阅读按钮复用输入区的同一播放器：准备中可取消，播放中可暂停，再次点击继续；完成后可复用音频重新朗读。优先读取已提交句子，首页使用输入文本。准备期间不会启动高亮。设置展开为圆角面板，左向描边返回按钮回到菜单，初期只显示「角色设置」与「收起」。收起销毁角色渲染器，胶囊保留在角色原位置，仍能聊天或恢复角色。胶囊不显示独立的互动或动作按钮，直接轻点角色部位即可互动。

角色点击按模型声明的 HitAreas 命中，匹配 TapHead、TapBody、TouchHead 等部位动作组。头部与身体区域重叠时优先头部；缺失对应动作时不借用其他部位或待机动作。其他部位可按声明名称匹配 TapLeftArm 等动作。只有实际命中且存在对应动作（或明确的通用 Tap/Touch/Interact 组）才会播放。当前 SDK 样例 Hiyori 只有 Body 区域与 TapBody，未提供独立头部区域及动作；应用不会自动生成缺失的动作资源。

服务通过统一能力目录适配模型，当前目录包含头部、身体、左右手、左右臂、左右腿及思考/成功/困惑反馈；自定义部位可用相应 Tap/Touch 命名直接匹配。导入时登记所有动作组、每组动作数量及表情，检测明确命名的用途并生成能力表；运行时再校验命中区引用的 drawable，点击通过该表分发，未声明的动作组、无效序号或表情 ID 不会执行。情绪反馈优先使用识别到的表情，其次使用对应动作，无专属资源时继续使用现有的通用骨骼反馈。

「设置 → 虚拟角色服务」默认显示角色设置，可进入「动作与表情」或「互动设置」；内部通过唯一的「返回角色设置」入口返回，不再提供重复的「角色」按钮。动作与表情页列出真实用途，并支持就地预览、改名和“用于…”配置；互动设置按平时动作、点击部位、快捷键和伴学反馈显示有效规则。两个页面使用同一份配置，自动用途与手动用途不会分别统计成相互矛盾的状态。旧配置自动迁移到版本 2，原资源 ID、别名、热区、快捷键、禁用与缺失引用保留。

点击和拖动统一由角色外层处理，按下、释放配对且移动小于 5px 才算轻点；拖动后移回、取消手势或丢失捕获不会触发动作。聚焦角色后 Enter/空格触发默认身体互动，Shift+Enter 请求头部互动，方向键继续移动。手动动作单次播放，新指令替换旧指令；播放期间伴学情绪不抢占，也不延迟补播。

角色舞台的虚线焦点提示由键盘导航意图控制：Tab 聚焦或使用方向键、Enter/空格操作时显示，鼠标按下时清除。初始加载与鼠标点击、拖动均不显示整块舞台边框；不通过强制失焦隐藏提示，角色仍可继续接受键盘互动。

大小与口型灵敏度在角色设置中调整；在角色区域按住 Ctrl 滚动（包括触控板捏合）也可缩放。预览即时更新，停止操作约 200ms 后保存。大小范围为 0.4–2.5 倍，舞台与画布随倍率同步调整，胶囊保持独立尺寸，并受可视视口限制。删除模型时清理对应记忆。

角色更新与口型采样共用独立 Pixi ticker。操作、语音和姿态过渡时最高 60fps，闲置 8 秒后以 15fps 保留待机动画；隐藏页面或角色不可见时停止动画，重新显示时恢复。启用「闲置时暂停动画」会将闲置低帧率替换为静帧。上述帧率为上限，实际帧率取决于设备与模型复杂度，不代表整页功耗归零。收起或关闭时销毁模型与渲染器。

真实解析任务开始时进入思考状态，成功或失败时短暂反馈约 3.5 秒后回归待机；取消会立即复位。恢复已有缓存结果不重复庆祝。表情按资源名称保守匹配 Think/Doubt、Smile/Happy/Joy、Confus/Sad，未匹配时用小幅骨骼偏移。不同模型并不保证有相应表情或骨骼。

朗读气泡只显示当前短句，朗读到的词与页面原文同步高亮，下一句开始时自动切换。无标点的长段也会切分；气泡保持约三行的基础高度，最高 132px，并按实际视口限制宽高和位置。暂停保留当前句与高亮，拖动进度和重播会重新定位。优先使用语音服务的词时间戳；未提供时按音频总长与日语读音估算。系统语音优先使用浏览器的词边界事件，缺少事件时采用近似跟读，精度受语音服务及系统支持影响。

气泡为装饰性副本，不重复向屏幕阅读器播报。有词持续时间时，两处高亮按音频当前时间连续扫过词内：正文使用柔边填充底板，气泡使用字素遮罩和文字颜色扫光。切词保留短暂的淡化衔接，文字节点始终稳定；逐帧进度只更新局部样式，不触发 React 逐帧渲染。暂停冻结进度，跳转立即校准；系统语音仅提供词边界而没有持续时间时保留整词高亮。换句使用短暂的透明度过渡。朗读结束后保留最后一句及当前词，以 150ms 淡出整块气泡和尾巴，再移除。减少动态效果时显示完整当前词并保留轻量透明度变化。

它与页面共用一个跟读时钟；音频口型解码独立优先使用离线 Web Audio，并限制到两个并发任务。口型解码失败不会停止音频播放器或跟读高亮。

## 发布前的许可核查

允许用户自由导入多个模型的应用，可能符合 Live2D 的 *Expandable Application* 定义。Live2D 官方要求此类应用在发布前接受审核，并签订专门的发布许可协议；其要求也适用于一般用户及小规模企业。发布 Web 或桌面版前，应向 Live2D 核实本项目的适用类别、Core 分发许可和所需手续，并分别核对拟使用模型的版权与再分发条款。具体要求见 [Live2D Expandable Applications 说明](https://www.live2d.com/en/sdk/license/expandable/)及 [SDK 下载许可](https://www.live2d.com/en/sdk/download/web/)。

图标沿用 Lucide 的圆头描边 SVG，胶囊使用聊天、朗读和设置图标，返回使用 14px、1.7 描边的左向折线 SVG。来源与许可见 [Lucide](https://lucide.dev/icons) 和 `LICENSES/Lucide-LICENSE.txt`。设置开关、单选与滑块使用自定义圆角样式，轨道颜色随主题变化。


设置滑杆和 Live2D 内部滚动条提供弹簧阻尼及轻微视觉反馈，数值即时响应；系统开启「减少动态效果」时停用震颤。桌面、手机和独立预览使用同一画质策略：按实际尺寸、设备像素比和可视视口捏合倍率重建画布，低密度屏目标为 2× 超采样，最高 4× 且限制为 6MP/4096px（还受 GPU 限制）；遮罩按尺寸提升至 512/1024/2048，且遵守 GPU 边长限制。1× 屏的超采样会增加绘制像素量，低端设备仍需实测。低清原始纹理仍会限制放大后的细节。弹簧参数依据 [Motion useSpring](https://motion.dev/docs/react-use-spring)，渲染尺寸使用 [Pixi renderer.resize](https://pixijs.com/8.x/guides/components/renderers)。


角色拖拽区域禁止文本选择，连续点击不会选中附近文本；区域外的正文和控件正常操作。部位互动使用同一指针手势，移动达到 5px 后只进行拖动。滑杆圆球与轨道分层，填充和圆球水平位置同帧即时同步，弹簧仅用于按压缩放和轻微垂直反馈；不再绘制独立位置刻线。

### 动作管理与手动绑定

「动作与表情」列出每一个动作及表情，包括同一动作组里的所有编号。支持名称／文件路径搜索、类型筛选、逐个播放、停止、上一个／下一个和复位姿态／表情。预览使用独立模型与资源 URL，默认静音、不循环；完成状态检查实际动作管理器，不把加载 Promise 当作播放完成。切换、停止或关闭会取消旧请求，释放预览不会卸载桌面角色纹理。

动作可以任意命名，不改变文件或自动识别。稳定 ID 由资源类型、原始组名／表情名、序号和文件路径组成，同名表情也分别登记。每个触发方式选择「自动识别」「指定资源」或「禁用」，任何动作和表情都可以绑定到任意区域、伴学事件和快捷键，也可以同时绑定多处。缺失资源保留原绑定以供修复，不悄悄回退到其他动作。

模型缺少头部等 HitArea 时，可以在预览上画矩形热区，拖动移动、拖右下角缩放，也能通过百分比输入和优先级按钮调整。坐标归一化到模型原始画布，点击时应用模型逆变换，随角色缩放、位置及 DPR 变化保持对应位置。矩形不跟随骨骼变形，编辑时以复位姿态为参考；边框只在编辑器显示。自定义热区先于原生区域，重叠时列表靠前者优先。禁用或资源缺失会阻断当前命中，不触发下方区域。

鼠标、触屏和键盘共用绑定分发器。聚焦角色时 Enter／空格默认触发身体，Shift+Enter 默认触发头部（也支持设置为头部的自定义区域）。可添加字母、数字、Enter、空格和 Shift 组合，重复组合提示冲突。方向键保留移动，Ctrl／Meta／Alt、Tab、Escape 等不接受为动作键。文本输入框不触发角色快捷键，长按不重复播放。

名称、绑定、热区和快捷键保存在对应模型的 modelConfigs.interaction 中，切换模型或修改大小／灵敏度保持配置，删除模型时一起清理。修改沿用设置草稿：返回保留草稿，「保存设置」应用，「取消」放弃。重置只清除当前模型的互动定制，保留角色大小、灵敏度和其他模型。


### 角色工作台（资源管理重设计）

进入资源或互动页面会暂时收起设置侧栏，返回角色页恢复。桌面两栏分别滚动，导航和设置页脚始终保留；窄屏资源目录进入详情后可通过“返回动作列表”回到筛选位置。资源行选择与预览按钮分开，点击“用于…”可指定平时自动播放、点击角色部位、快捷键或伴学反馈。已有手动资源被替换时需明确确认；资源详情也可单独移除某一用途，不删除原始文件。

平时动作支持模型默认、自选清单和关闭播放。自选支持单项重复、多项随机（尽量避免连续重复）或顺序播放，以及动作完成后的间隔。实例自己的调度器接管待机，不与 SDK 自动待机并行执行；损坏资源在本次会话中跳过，其他有效动作继续播放。关闭 motion 不关闭独立呼吸、眨眼与视线，闲置暂停设置仍适用。

表情可以选择指定秒数后恢复或再次触发关闭，并可设为默认外观。伴学反馈可单独选择定时或事件结束后恢复；模拟事件可显式结束，真实事件变更或取消时也会恢复到当前模型的用户默认外观。每次替换、复位或销毁使旧定时器失效。当前不提供多表情叠加编辑。

互动规则旁的“试用”与预览舞台的点击／快捷键仅驱动独立预览，不执行真实解析或聊天请求。“试用待机”读取草稿中的清单；完成后点击停止。区域编辑与互动试用是不同模式；删除区域可撤销，并保留删除后对其他配置的编辑。区域矩形仍固定在模型画布上，不随骨骼变形。

动作资源支持单项循环预览，按真实动作结束续播，停止或切换资源后结束；不会修改待机清单。资源目录每页最多显示 50 项，全目录搜索和用途筛选仍有效。互动规则区分模型声明、按名称自动匹配及用户配置；试用模式显示实际命中和重叠区域优先级。

设置草稿统一在页脚保存，显示修改数量和应用到角色的具体摘要；保存后应用到桌面角色，取消时通过现有未保存提示放弃。切换角色和工作台标签不会丢失各模型配置草稿；新修改会清除先前的“设置已保存”状态。文件导入和移除依然是独立的本地资源操作。专用检查命令为 `npm run test:live2d`。

启用系统减少动态效果时，自动待机和视线跟随停止；显式预览及朗读仍可唤醒，调整大小会重绘静帧。设置对话框限制背景焦点，支持 Tab 循环和侧栏方向键导航。
